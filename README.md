# Happy Game

Projeto acadêmico da FIAP: website sobre uma desenvolvedora fictícia de jogos.

## Status

Estrutura inicial do projeto. Conteúdo, estilos definitivos e funcionalidades ainda serão desenvolvidos nas próximas etapas.

## Estrutura de pastas

```
happy-game/
├── index.html
├── projeto.html
├── jogos.html
├── contato.html
├── feedback.html
├── css/
│   └── style.css
├── imagens/
├── videos/
└── README.md
```

## Tecnologias

- HTML5
- CSS3

Nenhum framework, biblioteca ou template foi utilizado, conforme exigido pela atividade.

## Páginas

- **index.html** — página inicial
- **projeto.html** — detalhamento do projeto
- **jogos.html** — catálogo de jogos
- **contato.html** — formulário de contato
- **feedback.html** — confirmação de envio do formulário

## Como visualizar

Basta abrir o arquivo `index.html` em um navegador. O projeto funciona totalmente local/offline.
